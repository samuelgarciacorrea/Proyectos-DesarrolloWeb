# Aplicacion Presupuestos 

## Descripción
Este es un proyecto básico de Una aplicacion de presupuestos desarrollado con HTML, CSS y JavaScript. La aplicacion sirve para seguir tus ingresos y egresos atravez del tiempo

## Funcionalidades

- agregar ingresos
- agregar egresos
- eliminar ingresos
- eliminar egresos

## Propósito del Proyecto
El propósito de este proyecto es aplicar conocimientos básicos de:

HTML para la estructura.
CSS para diseñar la interfaz y mejorar su estilo
JavaScript para agregar la funcionalidad 


### Funcionamiento
- Se carga la pagina y se el total de dinero restante, dependiendo de cuanto dinero hayamos ingresado y de cuales son nuestros ingresos, podemos, agregar o eliminar egresos y ingresos
