# Reloj Digital ⏱

## Descripción
Este es un proyecto básico de Un reloj Digital desarrollado con HTML, CSS y JavaScript. La aplicacion muestra la hora actual, dia de la semana, del mes y el mes en que esta.

## Propósito del Proyecto
El propósito de este proyecto es aplicar conocimientos básicos de:

HTML para la estructura.
CSS para diseñar la interfaz y mejorar su estilo
JavaScript para agregar la funcionalidad 


### Funcionamiento
- Se carga la pagina y se  muestra la hora actual, dia de la semana, del mes y el mes en que esta.
- Y ya el usuario no debe hacer nada mas
